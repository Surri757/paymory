# Paymory · 账忘录

> 每一笔，都不白花。
>
> Every payment, remembered.

记的不是账，是日子。一家吃了很多年的店、一只陪着长大的狗、一把换过六次弦的琴，都值得一条一条被写进本子里。

## 这是什么

Paymory = Pay + Memory。在记账的基础上，给每一笔花费补上"记忆的细节"：在哪家店、吃了什么、距离今天多久、它陪伴了你多少天、一共为它花了多少钱。

两层模型，完全来自生活：

- **记忆**——一次原子事件：时间、地点、金额（可选）、做了什么、想说的话
- **档案**——你自建的任意主体：食堂、宠物、物品、人、订阅、演唱会……记忆挂到档案，档案页自动长出陪伴天数、累计金额、时间线

金额只是维度之一，没花钱的陪伴也是记忆（"带它去江边跑步，没花钱，它很开心"）。

## 当前进度：交互原型

打开 `prototype/index.html`（需与 `prototype/echarts.min.js` 同目录），或本地起服务：

```bash
npx http-server prototype -p 8377 -c-1
```

- **日常页**：温柔手帐——奶油纸纹、便签歪着贴、和纸胶带、简笔贴纸、楷体、红笔金额
- **回望页**：墨夜纪念册——金墨数据、总览/分档案切换、ECharts 图表、每档案一句专属结语
- **动效**：Apple HIG 参数体系——按下快松手弹、方向感页面转场（View Transitions）、sheet 判速跟手、触觉反馈
