# Paymory · 账忘录

> 每一笔，都不白花。
>
> Every payment, remembered.

记的不是账，是日子。一家吃了很多年的店、一只陪着长大的狗、一把换过六次弦的琴，都值得一条一条被写进本子里。

![深色桌面上摆着一台手机，屏幕里是十一月的手帐](docs/web-stage.jpg)

## 这是什么

Paymory = Pay + Memory。在记账的基础上，给每一笔花费补上"记忆的细节"：在哪家店、吃了什么、距离今天多久、它陪伴了你多少天、一共为它花了多少钱。

两层模型，完全来自生活：

- **记忆**：一次原子事件，有时间、地点、金额（可选）、做了什么、想说的话
- **档案**：你自建的任意主体，比如食堂、宠物、物品、人、订阅、演唱会。记忆挂到档案，档案页自动长出陪伴天数、累计金额、日历和时间线

金额只是维度之一。没花钱的陪伴也是记忆，比如"带它去江边跑步，没花钱，它很开心"。

## 网页版

`web/` 里是一期网页版，原生 HTML / CSS / JS，不需要构建，也没有第三方依赖。

```bash
npx http-server . -p 8377 -c-1
```

然后打开 `http://127.0.0.1:8377/web/index.html`。手机上是整屏的本子，桌面上是摆在深色桌面里的一台手机。Chrome、Edge 111 起和 Safari 18 起有完整的页面转场，其余浏览器直接切换，功能一样。

![本子、档案夹、回望总览、单个档案四屏](docs/web-screens.jpg)

- **本子**：按天贴着的便签，有小票、拍立得、票根、印章四种形态，配和纸胶带、红笔圈和"第 N 次"的计数。点一张，它自己长成大卡
- **档案夹**：一本贴纸册，每个档案一枚。点贴纸，它长大成档案页的封面
- **档案页**：陪伴天数、来过几次、平均每次多少钱，这个月的脚印日历，还有本子上关于它的每一条
- **回望**：墨夜纪念册，一屏讲一件事。陪了你多少天，8 段陪伴加起来的 19 年，一张长小票，每 100 块花在了谁身上，哪个月的墨最重，所有的第一次。胶卷条随时在总览和单个档案之间切换，结尾可以存成一张卡片
- **贴一张**：标签栏正中的纸签，记一笔新的

现在跑的是演示数据，刷新即还原。本地存储、账单导入和支付感应都在后面的阶段。
